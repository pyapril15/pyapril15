# Fonts and icon sources

All assets are embedded inside the SVG files as base64 / inline paths. No network requests are made when the SVGs render.

## Fonts (embedded as base64 WOFF2, latin subset)
| Role | Font | Source | License |
| --- | --- | --- | --- |
| Display | Unbounded 800 and 600 | npm `@fontsource/unbounded` (googlefonts/unbounded) | SIL Open Font License 1.1, see `OFL-Unbounded.txt` |
| Mono | JetBrains Mono 400 and 700 | npm `@fontsource/jetbrains-mono` (JetBrains/JetBrainsMono) | SIL Open Font License 1.1, see `OFL-JetBrainsMono.txt` |

Brand marks are used only to identify the technologies and profiles they represent. Dark brand colours (Vercel, GitHub, Express.js) are drawn in off-white, and low-contrast colours are lightened so they stay legible on the navy cards.
